# Mysuru Dasara

A responsive, photo-led festival homepage built with Flask and Jinja templates.

## Run locally

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser. Mysore Dasara photos are stored locally in `static/images`; Google Fonts still require an internet connection.
